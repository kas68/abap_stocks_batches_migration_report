********************************************************************************
* HBM - Phase 1 : Batch Stock Transfer to New Plant (Split Valuation)
* Spec: FSD_TSD_HBM_SplitValuation_Phase1_ZHBM_SPLIT_VAL_PH1 v0.4
* Program version: v0.4 (message 023 added, no table change)
* DDIC objects to create in SE11 BEFORE activating ZHBM_SPLIT_VAL_PH1
********************************************************************************
* Log tables:
*   - ZLOT_MOV_EXEC  : one line per processed record / 301 attempt
*   - ZLOT_BATCH_EXT : one line per batch extension (BAPI_BATCH_CREATE)
* Both client-dependent, delivery class A, Display/Maintenance allowed.

================================================================================
DOMAINS / DATA ELEMENTS
================================================================================
Reuse standard: MATNR, CHARG_D, WERKS_D, LGORT_D, BWTAR_D, BWKEY, XCHPF,
MENGE_D, MEINS, BWART, BUDAT, MBLNR, MJAHR, SYMSGID, SYMSGNO, SYMSGTY,
ERNAM, ERDAT, ERZET.

Custom:
Data element ZLOT_RUN_ID   Domain CHAR32     Migration run id (base)
Data element ZLOT_RUN_SEQ  Domain NUMC3      Restart sequence (001,002,...)
Data element ZLOT_RUN_MODE Domain ZLOT_RUN_MODE (CHAR1)
   Fixed values: F = Full Validation Mode
                 D = Direct Transfer Mode
Data element ZLOT_STATUS   Domain ZLOT_STATUS (CHAR1)
   Fixed values: S = Success / posted
                 E = Error / blocked / excluded
                 W = Warning
                 T = Test / Simulation (not posted)
                 Z = Zero quantity - no movement
                 X = Skipped (reconciliation / not processed)
                 I = Inconsistent (SAP stock not in input file, segment exists)

location. MENGE carries the quantity of that posting line, QTY_INPUT the
quantity of the whole input-file line, so QTY_INPUT repeats across the
rows of the same line. All rows of one input line share MBLNR / MJAHR.

================================================================================
MESSAGE CLASS  ZHBM  (SE91) - used by the program
================================================================================
002  Zero quantity in input file - no movement created
003  Valuation type &1 not created in target plant &2
004  Quantity mismatch: file &1 vs SAP &2 (variance &3)
005  Cannot allocate &1 &2 to storage locations of plant &3 (&4 available)
006  No unrestricted stock in plant &1 for material &2 batch &3
007  Line &1: quantity &2 is not numeric - line rejected
008  Line &1: negative quantity &2 - line rejected
009  Line &1: layout error (field count / mandatory field) - line rejected
010  Inconsistency: SAP stock not in input file but valuation segment exists
011  SAP stock not in input file (no target segment) - not processed
012  &1 input line(s): batch column normalised to blank (placeholder value,
     or material not batch-managed)
013  Material &1 is batch-managed in plant &2 but the input line declares NO_BATCH
014  Material &1 is not extended to plant &2
015  Material &1 declares NO_BATCH but holds unrestricted batch stock in
     plant &2 (MCHB)
016  Batch &1 of material &2 split over several valuation types - batch
     rejected (one valuation type per batch)                        [v0.3]
017  Line &1: unit of measure &2 unknown - line rejected            [v0.3]
018  Unit &1 differs from base unit &2 of material &3               [v0.3]
019  Batch &1 exists in plant &2 with valuation type &3, file gives &4
                                                                    [v0.3]
020  Source batch &1 cannot be read in plant &2                     [v0.3]
022  Update failed after commit - document &1 not posted            [v0.3]
023  Storage location &1 does not exist in plant &2 - line not
     transferred                                                    [v0.4]
(The program currently passes free text in MSGTX; message-class entries are
 recommended so MSGID/MSGNO are meaningful for reporting.)
